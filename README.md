# 拼豆图纸微信小程序 MVP

这是一个不依赖服务器的原生微信小程序。用户选择图片后，小程序会在本地将图片缩放到指定网格，使用 Oklab 感知距离匹配 MARD 小豆 149 色参考板，并生成逐格纯色、逐格色号和材料数量清单。

## 第一版功能

- 从相册或相机选择图片。
- 设置 8～64 格的图纸宽高。
- 照片模式与像素图模式。
- 限制最多使用 8～48 种颜色。
- MARD 小豆 149 色 Oklab 最近色匹配。
- 透明像素自动转为空白格。
- 每格显示色号，每 5 格加粗网格线。
- 点击单格修改颜色或设为空白。
- 实时统计每种颜色的数量和占比。
- 显示盼盼、咪小窝、漫漫、babypinkin、VV 的参考换号。
- 导出带色号网格及图例的 PNG。

## 0.2.0 界面优化

- 图纸预览固定在独立窗口内，不再向下覆盖材料清单。
- 支持缩小、整图预览和放大。
- 小于 14px 的整图模式隐藏格内文字，放大后恢复色号，避免文字互相覆盖。
- 优化图纸区与材料区层级，以及全面屏手机的底部安全距离。

## 如何运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择本项目根目录。
3. 测试时可以保留 `project.config.json` 中的 `touristappid`；正式发布前换成自己的小程序 AppID。
4. 编译后，选择一张图片并点击“生成拼豆图纸”。

项目不需要安装 npm 依赖，也不需要配置服务器、域名或云函数。

## 数据口径

- 实际颜色匹配只使用 `MARD / small_reference_image34` 的 149 色参考板。
- MARD HEX 来自 [Pixelbead 291 色公开页面](https://www.pixelbead.art/zh/guides/mard-bead-color-chart)，只用于屏幕预览和算法匹配，并非官方实物测量值。
- “小豆”范围来自用户提供的跨品牌色号对照图；来源没有明确写出 2.6 mm，因此程序界面没有宣称其为官方 2.6 mm 色卡。
- 盼盼、咪小窝、漫漫、babypinkin、VV 目前只有参考换号，没有各自独立 RGB。切换这些品牌只改变显示色号，不改变匹配颜色。

这条边界很重要：不能把 MARD RGB 复制给其他品牌，否则会让用户误以为不同品牌实物完全等色。

## 算法流程

1. 读取本地图片并按目标网格比例居中裁剪。
2. 照片模式开启平滑缩放；像素图模式关闭平滑缩放。
3. Alpha 小于 128 的像素设为空白格。
4. 将每格 sRGB 转为 Oklab。
5. 与 149 色预计算 Oklab 向量计算欧氏距离，选择最近颜色。
6. 若颜色数量超过上限，保留使用量最多的颜色，并把其余颜色重新映射到保留色。
7. 生成材料清单；人工改单格后实时重新统计。

核心算法位于：

- `miniprogram/utils/color.js`
- `miniprogram/utils/grid.js`
- `miniprogram/utils/draw.js`

## 色卡更新

内置色板位于 `miniprogram/data/palette.js`，由脚本生成，不建议手工修改。

如果旁边仍保留完整的色卡 JSON，可以运行：

```bash
node scripts/build-palette.js
```

或指定源文件：

```bash
node scripts/build-palette.js /absolute/path/to/palette.json
```

## 本地检查

需要 Node.js 18 或更高版本：

```bash
npm run check
```

该命令会检查 149 色完整性、RGB/HEX/Oklab、六品牌映射数组和核心匹配算法。

## 发布前必须处理

- 将 `touristappid` 换成正式 AppID。
- 在微信公众平台完善隐私保护指引，说明相册、相机和保存到相册的用途。
- 使用至少 10 张图片进行真机测试，覆盖透明 PNG、照片、像素图、横图、竖图和 64×64 大网格。
- 用实体拼豆验证肤色、浅灰、粉红、蓝紫等相近色，再决定是否调整屏幕参考值。
- 获得其他品牌独立色卡后，才能增加“按品牌重新匹配”功能。
